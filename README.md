# Charity: water – Donation Landing Page

Project Overview

A responsive landing page concept for a new individual donation program inspired by the charity: water.
The page focuses on encouraging recurring monthly donations by showing how even a small contribution can help communities gain access to clean water.
The design follows the charity: water visual identity, using its recognizable yellow and dark blue color palette, clear typography, and a simple call to action.


Features
* Responsive layout for desktop, tablet, and mobile devices
* Responsive logo variations for different screen sizes
* Clear call-to-action button

Technologies Used
* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* Google Fonts

AI-Generated Image
The hero image was generated using AI specifically for this project, based on the project brief. It was created to support the visual concept and communicate the connection between access to clean water, education, and future opportunities.

Project Goal
To create a visually engaging, accessible, and responsive landing page that communicates the impact of small recurring donations and encourages visitors to take action.

This is an independent educational project and is not affiliated with or endorsed by charity: water.
